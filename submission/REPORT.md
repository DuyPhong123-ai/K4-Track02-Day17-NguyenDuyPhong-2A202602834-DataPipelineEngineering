## 3. Technical choices

- MERGE updates keyed entities and the LSN guard prevents older batches from reverting state. Feature partition replacement recomputes user/day aggregates without double counting late events.
- Silver tombstones retain the key and LSN so replay cannot resurrect deleted tickets; the trade-off is retaining tombstone rows indefinitely.
- Training is rebuilt from Bronze as-of the ingestion day, using priority at creation to avoid leakage. Versioned snapshots preserve reproducibility.
- DuckDB handles local SQL/Parquet at this small scale; Python handles validation and PII. dbt adds declarative models, contracts and tests plus an independent parity implementation. Spark would add unnecessary infrastructure.
